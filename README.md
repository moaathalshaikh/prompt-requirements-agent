# Prompt Requirements Agent

This project explores the intersection between Requirements Engineering and Prompt Engineering using AI Agents.  
Implemented as part of the university assignment for exploring the new AI Agent Mode in VS Code.

## Features
- Generate software requirements from natural language prompts using LLM.
- Example implemented in Python using OpenAI API (or simulation if offline).
